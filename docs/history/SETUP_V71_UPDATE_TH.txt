FISH POS V71 — อัปเดตใช้งานหน้าร้าน

1) หลังพิมพ์ใบเสร็จ Epson สำเร็จ
- หน้าชำระสำเร็จค้างไว้ 3 วินาที
- จากนั้นกลับหน้าขาย/รายการสินค้าใหม่อัตโนมัติ
- Customer Display กลับหน้ารอออเดอร์พร้อมกัน
- ถ้าเครื่องพิมพ์มีปัญหา จะไม่บังคับปิดหน้าสำเร็จจากเงื่อนไขพิมพ์

2) รายการสั่งล่วงหน้า
- เพิ่มปุ่มสีส้ม "พิมพ์ใบเตรียม" ที่มองเห็นชัดในทุกออเดอร์
- พิมพ์ตรง Raspberry Pi -> Epson Wi-Fi โดยไม่เปิด Print dialog
- ใบเตรียมแสดง: โลโก้, ชื่อลูกค้า, เบอร์, วันที่รับ, เวลารับ, รายการ, ราคาต่อชุด, จำนวนชุด,
  ยอดแต่ละรายการ, จำนวนรวม, ยอดรวมตัวใหญ่, หมายเหตุ และผู้บันทึก
- ออกแบบให้เอาไปแปะหน้าร้าน/จุดเตรียมของได้ อ่านราคาและจำนวนชุดได้เร็ว

ระบบเดิมจาก V70 ยังคงอยู่ทั้งหมด
